# Reference material

Detailed capability research, legacy project documents, historical audits, third-party source archives, and screenshots are intentionally stored in the shared TeaseScript AI project research archive rather than this Git repository.

Repository reference files may provide concise, maintained summaries and routing for current design work. They remain non-authoritative unless a current specification or accepted ADR explicitly adopts a conclusion.

- [`PLAYER-UI-RESEARCH.md`](PLAYER-UI-RESEARCH.md) summarizes the browser-first player UI research used by issue #77 and routes to the current planning draft and executable examples.

Do not copy historical syntax or architecture into implementation merely because it appears in reference material.

Use `../CAPABILITY-MATRIX.md` for the repository-level capability summary and `../DOCUMENTATION-OWNERSHIP.md` for the storage boundary.
