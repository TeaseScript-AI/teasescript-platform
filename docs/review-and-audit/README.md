# Implementation, review, and audit guidance

Use one route by default:

- Before implementation, for final self-review, or for an explicitly assigned pull-request review,
  read [`IMPLEMENTATION-AND-REVIEW.md`](IMPLEMENTATION-AND-REVIEW.md).
- For an explicitly assigned audit, read [`AUDIT.md`](AUDIT.md).

Do not load the other route unless the task requires it. Both documents reuse repository authority,
finding, evidence, testing, and documentation rules by reference.
