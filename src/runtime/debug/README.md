# Debug

What a host sees of a run besides its events.

- `debug-trace.ts`: the debug trace: why values have the values they have.
- `debug-trace-limits.ts`: the debug trace's retention limits.
- `inspection.ts`: a detached, read-only view of a plan and a snapshot for a debugger.
- `instruction-trace.ts`: what a call executed, and the instruction observer.
